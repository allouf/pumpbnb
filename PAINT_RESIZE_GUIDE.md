# Paint Resize Guide for $CRAZY Banner 🎨

**Issue**: You set it to 1500x1500, but banner needs to be 1500x500  
**Fix**: Change the HEIGHT to 500 pixels  

---

## 🛠️ Step-by-Step in Paint:

### **Step 1: Open Your Banner Image**
1. Right-click your banner file: `kLOji6rqeUcntDWPg9Jj-mZqSq4.jpg`
2. Click "Open with" → "Paint"

### **Step 2: Access Resize Tool**
1. In Paint, click the **"Resize"** button (in the Home tab)
2. OR use keyboard shortcut: **Ctrl + W**

### **Step 3: Set Correct Dimensions**
1. **Select "Pixels"** (not percentage)
2. **UNCHECK "Maintain aspect ratio"** ← This is the key!
3. Set dimensions:
   - **Horizontal**: `1500` ✅ (you got this right)
   - **Vertical**: `500` ← Change this from 1500 to 500
4. Click **"OK"**

### **Step 4: Save Your Banner**
1. File → "Save as" → "PNG picture"
2. Name it: `CRAZY_banner_1500x500.png`

---

## 🎯 Why 1500x500?

**Banner Requirements:**
- **Width**: 1500 pixels (horizontal)
- **Height**: 500 pixels (vertical)
- **Ratio**: 3:1 (three times wider than tall)

**Your Current**: 1500x1500 = 1:1 (square)  
**Need**: 1500x500 = 3:1 (wide banner)
