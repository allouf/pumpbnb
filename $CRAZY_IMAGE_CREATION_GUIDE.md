## 🛠️ Step-by-Step Process:

### **Using Bing Image Creator (Recommended):**

1. **Go to Bing Image Creator**
   - Visit: https://www.bing.com/images/create
   - Sign in with Microsoft account

2. **Create Main Image**
   - Paste the main image prompt
   - Click "Create"
   - Wait for 4 variations to generate
   - Click on the best one to view full size
   - Right-click → "Save image as"
   - Name it: `CRAZY_main_1000x1000.png`

3. **Create Banner Image**
   - Clear the prompt box
   - Paste the banner image prompt
   - Click "Create"
   - Choose the best variation
   - Save as: `CRAZY_banner_1500x500.png`

4. **Check Dimensions**
   - Right-click saved files → Properties → Details
   - Verify dimensions are correct
   - If not, try generating again or resize
