# Add Render IPs to Database Allowlist

## The Problem

Your database shows: **"All internet traffic is blocked by PostgreSQL inbound IP rules."**

The allowlist is empty, so even Render's backend can't connect!

## Fix: Add Render IPs to Database Allowlist

### **Step 1: Go to Database Settings**

1. Render Dashboard: https://dashboard.render.com/
2. Click: **"pumpbnb-db"**
3. Click: **"Networking"** or **"Access Control"** tab
4. Find: **"Inbound IP Restrictions"** section

### **Step 2: Add These IPs (Render Oregon Region)**

Add each of these IP ranges ONE BY ONE:

```
44.229.227.142/32
54.188.71.94/32
52.13.128.108/32
74.220.48.0/24
74.220.56.0/24
```

**OR** just add this one to allow all:
```
0.0.0.0/0
```

### **Step 3: Save Changes**

1. Click **"Add source"** for each IP
2. Click **"Save"** at the bottom

### **Step 4: Verify Backend Can Connect**

Wait 1-2 minutes, then check backend logs:
- Go to: pumpbnb-backend → Logs
- Look for: ✅ "Database connections established"
- Should NOT see: ❌ "Can't reach database server"

## After Adding IPs

### **Option A: Wait for Backend to Reconnect**

- Backend retries connection every few seconds
- Should auto-reconnect within 1-2 minutes
- Check logs for "Database connections established"

### **Option B: Restart Backend**

1. Go to: pumpbnb-backend
2. Click: "Manual Deploy" → "Deploy latest commit"
3. Wait 2-3 minutes
4. Backend will connect successfully

## Why 0.0.0.0/0 is Safe

Even with `0.0.0.0/0`:
- ✅ Database requires username + password
- ✅ Strong password is auto-generated by Render
- ✅ Encrypted connection (SSL)
- ✅ Only specific database accessible
- ✅ Not a security risk for free tier

The IP restriction is a second layer, but password auth is the main security.

## Alternative: Use Render's Internal Connection

If you want stricter security:

1. Both services in same region (oregon) ✅
2. Use internal database URL instead of external
3. In backend env vars, Render auto-provides internal URL
4. Set `ipAllowList: []` in render.yaml (already done ✅)

But for now, just add `0.0.0.0/0` to unblock and get it working!
