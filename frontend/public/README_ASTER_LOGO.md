# ASTER Logo Setup

The ASTER logo should be placed as:
- `public/aster.webp` - The main ASTER token logo image
- `public/aster.svg` - SVG fallback (already created)

The AsterLogo component will automatically use aster.webp if available, with fallback to aster.svg.

## Expected Image Specifications:
- Format: WebP
- Recommended size: 64x64px or higher
- Should be circular or will be displayed as circular
- Should have transparent background or proper circular design
